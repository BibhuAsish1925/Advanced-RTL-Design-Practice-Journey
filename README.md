## 📌 Overview

- **13 Learning Phases** covering RTL design through hardware security.
- **125 Numbered Practice Modules** across digital design and verification topics.
- Individual phase folders contain detailed documentation for their respective modules.

## 🛠️ Tools & Technologies

- **HDL:** Verilog, SystemVerilog
- **Simulation:** AMD Vivado, EDA Playground, Icarus Verilog, Verilator
- **Verification:** Self-checking testbenches, reference models, constrained randomization, functional coverage, UVM
- **Design Concepts:** Datapaths, FSMs, arithmetic, memories, clocking, DSP, cryptography

## 📐 Design Philosophy

**Understand → Design → Simulate → Verify → Synthesize → Improve**

The goal is to build a strong foundation in RTL implementation and verification through progressively challenging digital hardware concepts.

## ⚠️ Note

This is a learning and RTL practice repository. Module functionality, verification completeness, synthesis results, and implementation quality depend on the individual designs and their validation.
